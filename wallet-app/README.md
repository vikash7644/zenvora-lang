# Fleur Wallet UI Prototype

A mobile-friendly, single-page UI prototype for the Fleur Network ecosystem:
- Wallet overview and demo address
- Send/receive interaction placeholders
- Simulated mining dashboard
- dApp hub placeholders for tokens, games, swaps and developer tools

## Run
Open `index.html` in a browser or serve this folder with any static web server.

## Important limitations
This is **not a production crypto wallet** and is not connected to a blockchain. FLR is a placeholder ticker; address generation is only a local demo identifier, mining rewards are simulated, and send/receive/smart-contract actions do not execute. It does not create, import, or store real private keys. Do not use it for real funds or enter seed phrases.

Production readiness requires a verified Fleur node/RPC, chain ID and address format, secure key management and transaction signing, chain-backed balance/history, consensus-backed mining, contract execution, tests, and an independent security review.
