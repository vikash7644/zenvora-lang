# QORVYNT Ecosystem Website

A responsive, dependency-free landing page for the QORVYNT project.

## Contents
- `index.html` — layout, styling and small navigation/reveal interactions in one static file.
- No package manager, framework build, API key or database is required for this landing page.

## Local preview
Open `index.html` in a browser, or serve the `website` directory with any static HTTP server.

## Vercel
Configure the Vercel project root directory as `website`. The site is static HTML and does not require a build command. After a successful deployment, verify the production URL from a logged-out/private browser window.

## Accuracy and safety
The page intentionally labels chain and language features by their current maturity. Do not change roadmap labels to “live” until the relevant implementation has been tested and verified. Never place private keys, API secrets or wallet seed phrases in this directory.
