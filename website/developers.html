How to write your first QORVYNT program

QORVYNT programs are written in plain text files ending in .qv. Open the browser playground, create or paste a program, and run it. The current language uses show to display output; it is the QORVYNT equivalent of a print statement.

hello.qvYour first program
show "Hello, world!"

What happens?

show evaluates the expression and writes its value to the program output. The text inside quotes is a string.

Current supported syntax

Output:
Hello, world!

Variables and calculations

variables.qvExample
define name := "QORVYNT"
define a := 20
define b := 22
define total := a + b

show name
show total

Use define name := value to create a variable. Use := to assign a new value to an existing variable. Arithmetic operators include +, -, * and /.

Conditions and loops

flow.qvExample
define score := 85
if score >= 50 {
    show "Pass"
} otherwise {
    show "Try again"
}

define count := 1
repeat count <= 3 {
    show count
    count := count + 1
}

Functions

functions.qvExample
fn add(left, right) {
    return left + right
}

define answer := add(19, 23)
show answer

Functions are declared with fn, accept parameters, and can return a value with return.

What is QORVYNT used for?

QORVYNT is an independently developed general-purpose programming language and developer-tooling project. Today, its prototype supports learning and experimenting with variables, expressions, functions, control flow, collections, and a stack-based virtual machine/bytecode workflow. Web apps, games, graphics, smart-contract deployment and a fully self-hosted compiler are longer-term goals—not finished capabilities yet.

Try these examples in the playground ↗More .qv examples ↗
Important: QORVYNT currently uses show, not a built-in print() statement in the documented core syntax. The compiler is still Rust-hosted while self-hosting is being developed. Check the project status before using it for production work.

collections.qvQORVYNT source
define scores := array(10, 20, 30)
define profile := map(
    "name", "Builder",
    "level", 1
)

show sum(scores)
show get(profile, "name")
show len(scores)
The contract/state/action/view syntax is an experimental local VM feature. It is not yet a decentralized smart contract, chain deployment format, or production financial system. Blockchain, wallet, token, DAO, game engine, and AI-agent capabilities must not be described as shipped until their runtimes and tests exist.
