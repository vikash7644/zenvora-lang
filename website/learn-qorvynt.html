Learn QORVYNT

A beginner-friendly introduction to writing programs in QORVYNT. Learn the .qv syntax with small examples you can read, edit and run.

Open browser playgroundBrowse .qv examplesGet CLI releases
Prototype status: The current compiler and VM are Rust-hosted. The browser playground is a JavaScript demo runner and does not yet provide full compiler/VM parity. The AI cartoon teacher and voice features are planned, not available yet.

1. Your first program

Create hello.qv:

define name := "QORVYNT"
show "Hello, " + name

define a := 10
define b := 20
show a + b

Expected output: Hello, QORVYNT and 30.

2. Variables

define score := 10
score := score + 5
show score

define creates a variable; := updates an existing variable.

3. Conditions

define age := 20
if age >= 18 {
    show "Adult"
} otherwise {
    show "Under 18"
}

4. Loops

define count := 1
repeat count <= 3 {
    show count
    count := count + 1
}

5. Functions

fn multiply(left, right) {
    return left * right
}
show multiply(6, 7)

Output: 42.

6. Arrays and maps

define numbers := array(10, 20, 30)
show numbers[1]
show len(numbers)

define person := map("city", "Patna")
show get(person, "city")

Run a program

Download a prebuilt CLI from the GitHub releases page. Newer CLI builds use:

qorvynt run hello.qv
qorvynt check hello.qv

The older v0.8.0 Prototype 1 release uses qorvynt hello.qv and qorvynt --check hello.qv. You do not need Android Termux to read this guide or browse the source.

What can QORVYNT do?

The current prototype demonstrates variables, expressions, conditions, loops, functions, strings, collections, modules and experimental contract syntax. Games, 2D/3D graphics, AI engines, web APIs, Web3 governance, GPU and USB integrations are part of the longer-term roadmap—not current built-in capabilities.
