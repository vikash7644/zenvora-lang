Playable browser prototype · 2D

Grid Quest

Move the glowing player to the green goal. Avoid the red blocks. The level can be edited in Zenvora syntax and previewed here. For the compiler-backed path, run `python scripts/export_game_level.py examples/game-2d-level.zv game-scene.json --zv ./target/release/zv` in the repository, then import `game-scene.json` below. That export executes the `.zv` program through the real Zenvora VM and validates a versioned scene descriptor. The browser handles input, collision, and Canvas drawing; arbitrary Zenvora game functions are not yet run by the graphical runtime.
