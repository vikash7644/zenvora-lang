# Supporting QORVYNT

QORVYNT is an independent open-source programming-language project under active development. Support is optional; code review, bug reports, documentation improvements, and sharing reproducible examples are equally valuable.

## GitHub Sponsors

Visit [github.com/sponsors/vikash7644](https://github.com/sponsors/vikash7644) to check whether sponsorship is currently enabled for the maintainer account. The repository's `.github/FUNDING.yml` points to that profile, but this file alone does not prove that the account has been approved or that payment methods are active.

If GitHub Sponsors is available, suggested voluntary amounts are:

- **$1** — a small thank-you
- **$5** — help with routine development costs
- **$10** — support testing and documentation
- **$25** — help sustain focused engineering time
- **$100** — larger one-time or recurring support

These are suggested amounts, not a statement that those exact tiers have been created on GitHub. The actual options shown by GitHub are authoritative. Do not send money if the official sponsor page does not present a working checkout.

## What support helps fund

- Compiler and virtual-machine engineering
- Regression testing, fuzzing infrastructure, and security improvements
- Language documentation, examples, and editor support
- Build, release, and project website maintenance

## Transparency

- QORVYNT is a work in progress; sponsorship does not imply a stable v1.0 release.
- Contributions do not grant equity, ownership, tokens, repayment, financial returns, or control over roadmap decisions.
- No charity registration, tax-deductible status, or tax receipt is claimed.
- Sponsorship is voluntary and does not guarantee feature delivery, support response times, or access to unreleased software.
- Public development status and completed work should be judged from repository commits, issues, releases, and passing CI—not fundraising claims.
