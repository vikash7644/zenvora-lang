# Security Policy

## Supported Versions

Zenvora is under active development. Security fixes are handled on a best-effort basis for the latest development branch.

| Version | Supported |
| ------- | --------- |
| Latest development branch (`self-hosted-compiler-foundation`) | Best effort |
| Other versions and releases | Not guaranteed |

## Reporting a Vulnerability

Please report security vulnerabilities privately to the repository maintainer rather than posting exploit details in a public issue.

- **GitHub repository:** https://github.com/vikash7644/zenvora-lang
- **Private reporting:** Use GitHub's **Security → Report a vulnerability** feature if private vulnerability reporting is enabled for the repository.
- **Expected response:** The maintainer will aim to acknowledge reports within 7 days and provide updates as the investigation progresses.
- **Accepted reports:** The issue will be assessed, and a fix or mitigation will be pursued where appropriate.
- **Declined reports:** The reporter will be informed when practical, with an explanation where possible.

Please include the affected component, steps to reproduce the issue, potential impact, and any proof of concept needed to verify it. Avoid publicly disclosing exploitable details before a fix is available.

## Security Disclaimer

Zenvora is under active development. Its compiler, virtual machine, bytecode execution, and blockchain-related functionality have not necessarily undergone independent security audits. Do not rely on experimental components for production systems or assets without appropriate testing and review.
